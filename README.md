# CS-370-13864-M01-Current-Emerging-Trends-in-CS-
Portfolio Reflection

For this project, I worked on the pirate intelligent agent in the Jupyter Notebook. Some of the code was already given to me, including the maze environment, helper functions, replay memory class, and the model-building code. The main part I had to create myself was the Q-training algorithm. I wrote the code that let the pirate move through the maze, choose actions, store experience, learn from rewards and penalties, and improve over time using deep Q-learning. This project showed me how reinforcement learning can be used for pathfinding and how neural networks can help an agent learn better actions.

This course helped me connect artificial intelligence to the larger field of computer science. Computer scientists solve problems by designing systems, building code, testing ideas, and improving solutions over time. Their work matters because software and intelligent systems affect how people live, work, and make decisions every day. In this project, I approached the problem like a computer scientist by breaking it into smaller parts, understanding the starter code, testing the model, and fixing errors step by step until the agent could train and move through the maze.

I also learned that computer scientists have ethical responsibilities to both the end user and the organization. We need to build systems that are accurate, safe, and understandable. End users should be able to trust that the system works the way it is supposed to. Organizations also depend on reliable and maintainable code. In AI work especially, it is important to think about how a system makes decisions, whether it is fair, and whether it could cause harm if it is not tested well. This project reminded me that good computer science is not just about making something work. It is also about making something responsible and useful.
